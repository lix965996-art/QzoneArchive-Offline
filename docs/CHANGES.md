# 相对上游的修改说明

基于 Gaoshu705/QzoneArchive 的 `dfe5b95a6b6202659fb5218b3f719a98b41fd6b4` 整理发布，修改日期 2026-09-21。本仓库是独立衍生版本，不是上游官方发布。

- `src-tauri/src/archive_export.rs`、`customer_archive.html`：新增 PDF / ZIP 导出、客户静态阅读页、中文交付说明、下载缓存复用、超时取消、请求方式回退、分片校验和安全替换。
- `archive.rs`：归档、存储位置、历史内容与本地媒体处理增强；支持可选独立路径配置。
- `qzone.rs`、`qlogin.rs`：登录与 QQ 接口适配、历史归档及错误处理调整。
- `lib.rs`：新增命令注册与独立缓存配置。
- 发布测试修复：为临时导出目录增加进程内唯一序号与原子创建，避免并行任务碰撞、互相清理目录导致写入失败；新增隔离回归测试。
- Android 预览版：增加独立合法包名、API 24/36 配置和构建脚本；手机端使用应用专属 SQLite/媒体目录，ZIP 在沙箱中生成后分块复制到系统文档选择器，避免大文件一次性进入内存；隐藏依赖桌面 Edge 的 PDF 功能。
- `src/views`、`src/utils`、`src/stores`、样式：导出界面、任务与媒体交互、存储设置及明确标注的网页演示模式。
- 发布整理：独立应用标识，避免默认覆盖原版数据；移除本地签名密钥、个人迁移脚本、真实导出和未经审查的旧截图；新增中文文档、演示图、测试与构建流程。
