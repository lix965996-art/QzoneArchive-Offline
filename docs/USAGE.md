# 安装、导出与交付

## 安装

下载 Release 中的 `QzoneArchive.Offline_1.2.4_x64-setup.exe`（实际文件名以 Release 为准），双击安装。未使用商业代码签名证书；如系统提示未知发布者，请先核对下载来源和 Release 中的 SHA-256，不要关闭系统安全防护。

本公开版使用独立应用标识，默认与旧版数据隔离。已有用户请先备份旧数据；如需继续使用已有完整数据目录，可在设置中选择该目录，确认路径后再操作。不要同时启动两个程序写同一数据库。本次发布不会自动搬动已有数据。

## 操作

1. 登录本人或已授权账号。
2. 运行需要的归档任务；遇到限流暂停后再继续。
3. 进入归档内容，选择分类和时间范围。
4. 点击分享 ZIP。选中记录时仅导出所选内容；未选中时按当前分类和时间导出。
5. 建议勾选 PDF。按年份拆分便于查找；大批内容也会自动分册。
6. 导出后先完整解压自查：正文数量、图片、视频播放、PDF 和缺失说明。

## 给接收方的一句话

> 请先完整解压这个 ZIP，再用 Edge 或 Chrome 打开“开始阅读.html”。不要单独移动网页文件。手机可以先读 pdf 文件夹内的 PDF；视频请在解压后的网页或播放器观看。

## 常见问题

### 网页里能看，交付包却缺图？

程序界面可能使用当前账号权限、远程链接或浏览缓存。交付包只能包含真正成功保存下来的资源。本版复用本地媒体并尝试不同请求方式，但不保证失效源地址一定可恢复。

### 为什么还会有未收录项目？

可能是旧地址、权限、超时、服务端删除或原始记录缺少有效地址。查看“导出说明.html”。重新登录、在授权范围内更新归档后重试；缓存中已有的文件会复用。不应把“占位图”直接理解成永久删除，也不应把未收录项算作成功交付。

### PDF 没有视频？

PDF 用来阅读正文和图片。可播放视频在 ZIP 的 media 文件夹，解压后的网页提供播放控件。

### 只看见界面，抓取和导出没有实际发生？

`npm run dev` 打开的浏览器页面是演示模式。必须用 Tauri 桌面版执行真实抓取和导出。
